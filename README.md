# 坦克大战

一个用纯 HTML + Canvas + JavaScript 编写的经典坦克大战小游戏。零依赖，双击 `index.html` 即可游玩。

## 操作

| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` / `WASD` | 移动 |
| `空格` / `J` | 发射 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `回车` | 开始 / 重新开始 |

移动端会显示虚拟按键。

## 玩法

- 消灭所有敌方坦克即可过关，保护你的基地不被摧毁。
- 砖块可被击穿，钢板无法摧毁，水域阻挡坦克但不挡子弹，草丛可以藏匿坦克。
- 敌人分为：普通、高速、重装（2 点生命）、装甲（3 点生命）。
- 拥有 3 条生命，分数随关卡与敌人类型提升。

## 运行

直接用浏览器打开 `index.html`，或在仓库设置中开启 GitHub Pages 后访问线上版本。
